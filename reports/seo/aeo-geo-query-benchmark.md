# AEO/GEO query benchmark

Baseline date: 22 October 2026. See [query-observations.json](query-observations.json) for exact queries, timestamps and every returned URL. Eight separate unquoted informational queries were sent through the available web-search tool. The underlying engine, location, personalization and complete result ordering are not exposed. This is an accessible-result observation, not a Google/Bing rank tracker.

**Observed:** no zqtion.com URL occurred in the returned result set for any of the eight queries. This does not prove absence from the whole index, zero traffic or zero AI citations. No post-deployment comparison exists because this candidate has not been deployed.

| Query | Examples observed in the returned set | Evidence relevance to review |
|---|---|---|
| How do I build a low-cost AI automation workflow? | Mamba Digital; Zapier; Microsoft Learn | Inspect concrete steps and current pricing sources, not headline savings |
| Best way to evaluate AI coding prompts | Vercel evaluation guide; evaluation.treasury.gov.au | Look for fixed tasks and observable success criteria |
| How does an MCP server work? | Microsoft Learn; Slack developer docs | Primary implementation references are stronger than generic definitions |
| How to build an AI lead research pipeline | Parallel; iTechGuides | Check whether claimed outcomes have reproducible source evidence |
| What tools can run document analysis locally? | lawyers-assistant.github.io; local-doc-analyzer GitHub repository | Check actual offline mode, network paths and document/privacy limits |
| How do people use AI agents in real businesses? | AP; The Atlantic and other returned sources | Independent reporting is not direct evidence of Zqtion outcomes |
| Examples of useful open-source lead research tools | awesome-ai-lead-generation; awesome-gtm GitHub lists | Lists reveal alternatives; test license, maintenance and fit separately |
| How to evaluate prompts using real-world results | prompt-engineering.si; SurePrompts | Inspect test inputs, evaluation criteria, raw evidence and limitations |

The listed pages are **observed discovery references**, not endorsed claims or verified competitor performance. Their snippets were not copied into articles. Technical implementation decisions use the primary documentation in the research report.

## Reproducible follow-up

After an authorized deployment and verified indexing, repeat the exact query set monthly in a recorded locale/account state. Retain provider, date/time, query, returned source URLs and relevant screenshots/exports. Separately sample Google AI Mode, ChatGPT Search and Copilot with their actual search-enabled products, recording answer text and exact linked URLs where allowed. Distinguish a direct Zqtion citation, a brand-only mention, a navigational link and no occurrence.

**AI answer tests: NOT RUN.** No generated local answer, simulated citation or web-search result is counted as a real Google/ChatGPT/Copilot answer. Access/configuration must be available before those measurements can be claimed. Make no causal traffic or ranking claim from a single repeated query. Track owner-accessible Search Console and Bing landing-page/referral data alongside these small samples.
