## Production sequence

1. **Manual validation:** interview a few intended readers or inspect real incoming questions; record the task and existing workaround. Write one source-backed outline and run a disposable test before writing an article.
2. **First publishable version:** one existing URL, concise answer, specific prerequisites, reproducible steps/example, actual limitations, source-backed costs if available, and human approval.
3. **Maintainable version:** retain raw evidence, content hashes, link checks and dated re-tests. Update when the underlying behavior changes; no automatic freshness dates.
4. **Advanced tooling:** add retrieval or evaluation automation only when it reduces measured editorial work. Agents may propose updates; editors approve factual claims and publication.
