The alleged case study is explicitly an implementation proposal at its existing URL. The “zero-cost” article no longer promises zero operating cost.

Historical generated publication/creation dates were cleared rather than used as actual publication evidence. updated_at records this real content edit; it is not a test/verification date.
- Kept the 28 IDs, slugs, categories, public URLs, relevant prerequisites, concepts, failure cases and copyable examples. Proposed designs are labelled. Tool reference links are starting points, not proof of every claim. Repetition remains an editorial weakness; the roadmap prioritizes replacing scaffolding with original evidence.
- Every one of these 28 fails the same explicit human-review test on its own evidence, not because the entire Resources route is blocked. The Resource Library, original Prompt Library, Insights, Work and eligible approved Community pages remain indexable.
- Generator entrypoints write only review candidates under reports; tests execute them against an isolated temporary tree and prove the public catalogue is untouched. No synthesis command was run against public content.
- Resource API/MCP envelope shapes are retained. Lookup and illustrative recommendations no longer invent verified dates, benchmark results or prices. Existing seeded composite stacks are exposed as unverified with costs not estimated. The MCP manifest descriptions also distinguish proposed resources from verified implementations and avoid stale model examples. Request handlers and tool envelope shapes are unchanged.
